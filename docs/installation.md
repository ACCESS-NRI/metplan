# Installation
## Stable release

To install metplan, run this command in your terminal:

```shell
$ pip install metplan
```

This is the preferred method to install metplan, as it will always install the most recent stable release.

If you don't have [`pip`](https://pip.pypa.io) installed, this [Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) can guide
you through the process.

## From sources

The sources for metplan can be downloaded from the [Github repository](https://github.com/ACCESS-NRI/metplan).

You can either clone the public repository:

```shell
$ git clone git://github.com/ACCESS-NRI/metplan
```

Or download the [`tarball`](https://github.com/ACCESS-NRI/metplan/tarball/master):

```shell
$ curl -OJL https://github.com/ACCESS-NRI/metplan/tarball/master
```

Once you have a copy of the source, you can install it with:

```shell
$ python setup.py install
```
